# 🎯 Jogo de Adivinhação

Um jogo simples de adivinhação desenvolvido em **Python**, criado para praticar conceitos básicos de programação, como variáveis, estruturas condicionais, laços de repetição, entrada de dados e geração de números aleatórios.

## 🎮 Como funciona

O computador escolhe aleatoriamente um número entre **1 e 100**.

O jogador possui **7 tentativas** para descobrir o número secreto. A cada palpite, o jogo informa se o número secreto é:

- 🔼 Maior que o palpite
- 🔽 Menor que o palpite
- 🎯 Igual ao palpite

Se o jogador acertar, o jogo informa que ele venceu. Caso contrário, após as 7 tentativas, o número secreto é revelado.

## 🕹️ Regras

- O número secreto está entre **1 e 100**.
- O jogador possui **7 tentativas**.
- Após cada tentativa, uma dica é exibida.
- O jogo termina quando o número é acertado ou quando as tentativas acabam.

## 🛠️ Tecnologias utilizadas

- 🐍 Python
- 📦 Biblioteca `random`

## 📚 Conceitos praticados

Este projeto foi desenvolvido para praticar:

- Variáveis
- Entrada de dados com `input()`
- Conversão de tipos com `int()`
- Estruturas condicionais (`if`, `elif` e `else`)
- Laço de repetição `while`
- Operadores de comparação
- Controle de tentativas
- Valores booleanos (`True` e `False`)
- Geração de números aleatórios com `random.randint()`
